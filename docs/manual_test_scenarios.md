# Сценарии ручного тестирования

## 1. Поиск и просмотр чужих результатов

1. Авторизоваться под `anna.sokolova` / `demo123`.
2. Открыть вкладку `Результаты`.
3. В поле поиска ввести `ivan` или `Иван Петров`.
4. Выбрать пользователя `@ivan.petrov` из списка.
5. Проверить:
   - в хедере открыт чужой профиль;
   - карточки результатов сгруппированы по дисциплинам;
   - внутри карточек видны лучший и последний результат;
   - по кнопке `Детали` открывается график прогресса и список всех результатов по дисциплине.
6. Нажать `Вернуться к себе` и убедиться, что снова открыты результаты `anna.sokolova`.

## 2. Добавление нового результата себе

1. Авторизоваться под `anna.sokolova` / `demo123`.
2. Открыть вкладку `Результаты`.
3. Нажать `Добавить`.
4. Сохранить результат, например:
   - дисциплина: `Бег 100 м`
   - результат: `12.98`
   - дата: любая актуальная
   - соревнование: `Тестовый старт`
5. Проверить:
   - новый старт появился в блоке `Бег 100 м`;
   - график дисциплины обновился;
   - в профиле обновилась история разрядов, если новый результат дал лучший разряд.

## 3. Просмотр группы участником

1. Авторизоваться под `ivan.petrov` / `member123`.
2. Открыть вкладку `Группы`.
3. Открыть группу `Сибирский темп`.
4. Проверить:
   - отображается код доступа группы;
   - в списке участников есть тренер и спортсмены;
   - отображаются лидерборды по дисциплинам;
   - записи в лидерборде отсортированы от лучшего результата к худшему.
5. Нажать на любой результат в лидерборде.
6. Проверить:
   - открывается детализация именно выбранного спортсмена и дисциплины;
   - показан график прогресса;
   - показаны все результаты этого спортсмена по дисциплине.

## 4. Переход из группы в результаты участника

1. Авторизоваться под `ivan.petrov` / `member123`.
2. Открыть `Группы` -> `Сибирский темп`.
3. В карточке участника нажать `Открыть результаты`, например у `Дарья Лебедева`.
4. Проверить:
   - приложение переключилось на вкладку `Результаты`;
   - открыт профиль `@daria.lebedeva`;
   - доступны дисциплинарные карточки и графики.

## 5. Апрув заявки тренером

1. Авторизоваться под `coach.romanov` / `coach123`.
2. Открыть `Группы` -> `Сибирский темп`.
3. Найти блок `Заявки на вступление`.
4. Проверить, что там есть `@nikita.frolov`.
5. Нажать `Одобрить`.
6. Проверить:
   - пользователь исчез из блока заявок;
   - пользователь появился в основном списке участников;
   - счетчик заявок в карточке группы уменьшился.

## 6. Подача заявки по коду доступа

1. Авторизоваться под новым пользователем либо под пользователем, который еще не состоит в группе.
2. Открыть вкладку `Группы`.
3. В форме `Вступить по коду` ввести `NORD2026`.
4. Нажать `Подать заявку`.
5. Проверить:
   - появляется сообщение об успешной отправке заявки;
   - группа появляется в списке со статусом ожидания апрува;
   - кнопку открытия группы нажать нельзя до подтверждения тренером.

## 7. Создание новой группы

1. Авторизоваться под любым пользователем, например `anna.sokolova` / `demo123`.
2. Открыть вкладку `Группы`.
3. В форме `Создать группу` заполнить название и описание.
4. Нажать `Создать`.
5. Проверить:
   - появляется сообщение с новым кодом доступа;
   - новая группа открывается сразу;
   - текущий пользователь отображается в ней как `Тренер`.
