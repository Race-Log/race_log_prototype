# Источник нормативов

Для текущего MVP в проект сохранены взрослые нормативы ЕВСК по индивидуальным беговым дисциплинам, барьерному бегу и стипль-чезу.

- Используемая редакция: действует с `26 ноября 2024 года`
- Основной источник: ВФЛА, PDF `ЕВСК по легкой атлетике`
- Ссылка: `https://rusathletics.info/uploads/content/docs/lyubiteli/legkaya-atletika-dejstvuyut-c-26-noyabrya-2024-g-87b8cad5ee-1.pdf`

Что покрыто сейчас:

- Пол: `male` / `female`
- Дисциплины: индивидуальные беговые старты, барьеры, `2000/3000` с препятствиями
- Параметры результата: авто/ручной хронометраж, круг `200/400`, для `2000 м с препятствиями` вариант `с водой / без воды`

Что оставлено на следующий этап:

- Возрастные группы кроме взрослых
- Прыжки, метания, многоборье, эстафеты, спортивная ходьба
