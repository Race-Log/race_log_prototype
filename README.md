# Race Log

Мобильный SPA для учета беговых результатов, просмотра чужих профилей, дисциплинарной аналитики и работы с тренировочными группами.

## Что есть сейчас

- регистрация, вход и профиль спортсмена
- добавление результата с автоопределением разряда
- просмотр своих и чужих результатов через поиск по логину или имени/фамилии
- группировка результатов по дисциплинам
- графики прогресса по каждой дисциплине
- группы с кодом доступа, заявками на вступление и апрувом тренера
- просмотр участников группы и лидерборды по дисциплинам по лучшим результатам

## Структура

- `web` - React SPA
- `back` - FastAPI API
- `db` - Flyway SQL-миграции
- `scripts` - `docker-compose.yml` для запуска всего стека
- `docs/manual_test_scenarios.md` - сценарии ручной проверки

## Запуск

```bash
cd scripts
docker compose up --build
```

После старта:

- web: `http://localhost:8080`
- back: `http://localhost:8000`
- healthcheck: `http://localhost:8000/health`
